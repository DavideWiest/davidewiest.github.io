Prepretraining first trains a language model on synthetic tasks, then transfers it to natural text. \href{https://github.com/Axym-Labs/pptrain}{\texttt{pptrain}} turns paper-specific generators and training scripts into one testable interface.

\section{Run a task}\label{run-a-task}

\begin{verbatim}
pip install pptrain
\end{verbatim}

\begin{verbatim}
from pptrain import PrePreTrainer, RunConfig, create_task
from pptrain.integrations import HFCausalLMAdapter, HFModelConfig

trainer = PrePreTrainer(
    task=create_task("simpler_tasks", {
        "preset": "paper_binary_1m",
        "sequence_count": 256,
        "eval_sequence_count": 64,
        "max_length": 128,
    }),
    model_adapter=HFCausalLMAdapter(
        HFModelConfig(model_name_or_path="sshleifer/tiny-gpt2")
    ),
    run_config=RunConfig(output_dir="runs/initial", max_steps=20),
)

bundle = trainer.fit().load_transfer_bundle()
\end{verbatim}

The packaged task families cover neural-cellular-automata rollouts (\texttt{nca}), balanced brackets (\texttt{dyck}), abstract programs (\texttt{procedural}), copy/set/query transformations (\texttt{simpler\_tasks}), mathematical-reasoning primitives (\texttt{lime}), and synthetic document transformations (\texttt{summarization}). Paper-derived presets remain configurable.

\section{Test the mechanism}\label{test-the-mechanism}

Reference-parity checks compare local outputs with original-source fixtures for LIME, synthetic summarization, procedural training, and NCA. The evaluation path tests downstream transfer against random initialization and natural-text warmups, and exports metrics, plots, CSVs, and reports through the same task interface.

Custom symbolic generators implement \texttt{SymbolicTaskFamily}: sample, execute, serialize, and tokenize an example. Tasks requiring a different dataset or loss path implement \texttt{Task} directly.
