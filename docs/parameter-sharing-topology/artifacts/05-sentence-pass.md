# Sentence pass

- Summary sentence 1 should define the concept before giving the result: parameter sharing chooses positions for reused operators.
- The max-distance paragraph should appear before results and should state the hypothesis without presenting it as the conclusion.
- Every result sentence should name the comparator. "Cycle width sharing won" is underspecified; "cycle width sharing had the lowest mean validation CE among the matched sharing topologies" is precise.
- Avoid contrastive filler such as "not only" and "not merely." Use direct formulations.
- Avoid claiming a universal theorem. Use "architectural result" and "design rule" because the evidence is empirical but broad enough to transfer.
- Keep each citation attached to the mechanism it supports.
- Move caveat-like details into method facts. For example, "three seeds" and "100M tokens" belong in setup, not in a limitation paragraph.
- The CNN and structured-matrix section should be an implication section, not a list of unrelated citations.
