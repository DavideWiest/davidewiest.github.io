# Writing task: concise research-blog refresh

## Context

- [x] Document type: short technical blog posts for the user's personal website.
- [x] Audience: technically literate ML/research readers.
- [x] Purpose: preserve only the strongest claims, derivations, evidence, and practical interfaces.
- [x] Sources: the canonical chemokinetic PDF, the Jacobian draft, existing website posts, and checked primary literature.
- [x] Voice: concise, paper-like, and explicit about evidence versus interpretation.

## Workflow

- [x] Reduce each post to one common thread.
- [x] Separate established results, new arguments, empirical observations, and interpretations.
- [x] Verify the Jacobian/minimum-risk derivation before publication.
- [x] Check every retained citation against its claimed role.
- [x] Draft each sentence from an essential claim, definition, result, evidence item, or logical connection.
- [x] Remove recap, diary, redundant hedging, and nonessential examples.

## Final verification

- [x] Preserve all intended claims, evidence, and necessary qualifications.
- [x] Remove theoretical and linguistic imprecision.
- [x] Introduce every term before use and keep notation consistent.
- [x] Keep one clear path through each article.
- [x] Make causal and logical relations explicit.
- [x] Use formal, natural prose without promotional hooks or filler.
- [x] Trace every sentence to an essential content item.

## Deliberate exceptions
