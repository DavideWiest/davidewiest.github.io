Finsights is a newsletter-as-a-service platform for investors who want to stay informed about their holdings without manually checking prices. Users select which stocks to track, set their preferred notification schedule, and receive automatic performance summaries.

The backend is built with Python and Django, using MongoDB for data storage and TailwindCSS for the interface. Email delivery is currently blocked because Microsoft is restricting SMTP access, which is a reminder that infrastructure dependencies can break products in ways that have nothing to do with the code itself.
