LetoReader is a speed reader I built because the existing options were either subscription-based or lacked the customization I wanted. It supports chunking, pacing, and highlighting, and can import text from files or the clipboard. All data stays in the browser's local storage, which means no accounts, no tracking, and no server costs.

The interface is designed to be as minimal as possible because the point of a speed reader is to read, not to configure.
